Part I Grading Rubric: Machine

COSC530 — ISA Project

Total: 5.0 points. Deductions are graduated within each category. Take the single deepest applicable step per category (deductions within a category do not stack unless noted). Round the final score to the nearest 0.25.

If the submission does not compile, grade the Build category first. A submission that cannot be built or run is capped per that category, but still receives credit for any component that can be verified by reading the code.

Category A — Build and Structure (0.5 pts)

Does the Part I code compile and is the machine core factored into its own source file(s) as required?

Step Criterion Deduction

A1

Compiles cleanly, machine core in its own file, no external dependencies.

-0.0

A2

Compiles but emits warnings that indicate real problems (e.g., truncation, unused results on config parsing).

-0.25

A3

Compiles only after trivial fixes (missing include/import, one typo), OR machine core is not separated into its own file.

-0.5

A4

Does not compile; requires nontrivial edits to build.

-0.5 (and verify remaining categories by code reading only)

Category B — Configuration Parsing and Precedence (1.5 pts)

Command-line switches, config-file parsing, and the precedence CLI > file > default.

Step Criterion Deduction

B1

All switches parse; config file parses (# comments, whitespace-separated key/value, last-duplicate-wins); precedence is correct; -mem accepts no-suffix/K/M/G.

-0.0

B2

Minor gap: one or two switches or the -mem suffixes mishandled, but precedence is correct.

-0.5

B3

Precedence is wrong in one direction (e.g., file overrides CLI, or defaults override the file).

-0.75

B4

Config file not supported, OR precedence largely non-functional; only some CLI switches work.

-1.0

B5

Configuration essentially unimplemented (defaults only, switches ignored).

-1.5

Category C — Machine Memory (0.5 pts)

RAM allocation sized by mem, addressable by byte index, left uninitialized.

Step Criterion Deduction

C1

Allocates exactly mem bytes; address N indexes byte N; not pre-populated.

-0.0

C2

Allocated but size is off (rounding, unit error) or wrongly zero-initialized against spec.

-0.25

C3

Allocation present but not byte-addressable as specified (e.g., word-indexed).

-0.4

C4

No usable memory allocation.

-0.5

Category D — Register File and x0 Semantics (1.5 pts)

The 32x32-bit register file behind a read/write API, with x0 hardwired.

Step Criterion Deduction

D1

32 registers behind a read/write API; reads of x0 return 0; writes to x0 are discarded; enforced inside the API.

-0.0

D2

x0 semantics correct, but enforced ad hoc at call sites rather than inside the API (fragile for later parts).

-0.5

D3

Reads of x0 return 0 but writes to x0 are not discarded (or vice versa).

-0.75

D4

No read/write API (registers accessed as a raw array), OR x0 not special-cased at all.

-1.0

D5

Register file missing or wrong width/count.

-1.5

Category E — PC, Stack Pointer, and CSRs (1.0 pts)

Program counter, 16-byte-aligned initial SP, and the six CSRs.

Step Criterion Deduction

E1

PC present and non-addressable; SP (x2) initialized to memory size rounded down to a 16-byte boundary; all six CSRs present with correct numbers and read/write behavior (mhartid read-only, satp hardwired to 0 when -mmu off).

-0.0

E2

SP initialized to memory size but not rounded down to 16-byte alignment.

-0.25

E3

One or two CSRs missing/wrong number, OR satp/mhartid special behavior not honored.

-0.5

E4

PC missing, OR SP not initialized, OR CSRs largely absent.

-0.75

E5

PC, SP, and CSRs essentially unimplemented.

-1.0

Category F — Sign Extension (1.0 pts)

A function taking a value and a sign-bit index, extending to 32 bits, with no loops and no conditionals.

Step Criterion Deduction

F1

Correct for all sign-bit positions; contains no loops and no if/else/ternary/switch.

-0.0

F2

Correct output, but uses a conditional or ternary (violates the branchless restriction).

-0.5

F3

Correct output, but uses a loop (violates the restriction), OR fails on a subset of sign-bit positions.

-0.75

F4

Function present but incorrect for the common cases, OR relies on the host to sign-extend.

-1.0
